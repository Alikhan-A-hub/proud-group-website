# Proud Group of Institutions — Website

Website of **Proud School** (Village Bhobtian, Raiwind Road, Lahore) and **Proud Academy** (Main Sher Shah, 100 Feet Road, Raiwind Road, Lahore).

A static website: plain HTML, CSS and JavaScript, with no build step.

## Pages
- `index.html`: Home (with opening intro)
- `about.html`, `founder.html`, `faculty.html`
- `proud-school.html`, `proud-academy.html`
- `admissions.html`, `facilities.html`, `gallery.html`, `contact.html`
- `blog.html` and `blog-*.html` posts

## Files
- `styles.css`: all styles
- `site.js`: menu, forms (WhatsApp inquiry), FAQ, gallery filters, intro
- `img/`: logo and photos
- `sitemap.xml`, `robots.txt`, `llms.txt`: SEO and AI search files

## Deploy
On Vercel, import this repository as a new project. Choose the "Other" framework preset and leave the build command empty.
If the site's domain changes, update the `BASE` address in the canonical links, `sitemap.xml`, `robots.txt` and `llms.txt`.
